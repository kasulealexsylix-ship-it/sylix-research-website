SYLIX RESEARCH CONSULTANTS WEBSITE

This is a ready-to-open static website.

How to view it:
1. Unzip the folder.
2. Open index.html in Chrome, Edge, or Firefox.

How to publish it:
- Upload the folder to Netlify, Vercel, GitHub Pages, or any web host.
- Buy a domain such as sylixresearch.com and connect it to the hosting account.

Important:
- The project request form sends details to WhatsApp.
- Real file upload and automatic payment confirmation need a backend/server in Version 2.
